# Fixurl

Tiny VB6 URL decoder (`Project1` / Fixurl) that turns percent-encoded text in `txtURL1` into a readable URL in `txtURL2` by replacing `%3a`, `%2f`, `%2e`, `%3f`, `%3d`, and `%26` as you type. Open `Project1.vbp` in the VB6 IDE.
